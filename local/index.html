Cert Decoder

Runs entirely in this browser tab. Nothing here is sent anywhere. Paste a full .ovpn file, a single PEM cert, or several — it'll find and label every block.

Decoded certs will appear here
Private key blocks (-----BEGIN PRIVATE KEY----- / RSA PRIVATE KEY) are detected and flagged but never parsed or displayed — treat any file containing one as a secret.
This is the fully local build: jsrsasign is vendored as jsrsasign.js in this same folder, not loaded from a CDN. Once you have this folder, it works with zero network access.
